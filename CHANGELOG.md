## 2026-09-19 — WFATest v0.3.0: probe, session log, spellbook; any class
- The maintainer asked whether the addon can find out what is loggable while playing other classes (Paladin, Mage, Druid) and log it for analysis. Answer: yes for state, no for individual casts. Built it.
- `/wfa probe`: about 60 reads (health, mana, XP, stats, target, threat, cooldowns, auras, casting, pet) stored as value / SECRET / MISSING / error, out of combat at once and by itself at the start of the next fight and 3 sec in. Also lists the function names in 14 API namespaces (C_DamageMeter, C_CombatLog, ...). `read_addon_data.py --probe` prints the in/out of combat matrix. This measures the open scope question in `docs/addon-feasibility.md` section 1.
- Session log, on by default (`/wfa auto off`): one small record on entered/left combat, XP, level up, zone, death, login; full snapshot with gear and spellbook on level up, gear change, talent change. State events only, no combat log events, no arithmetic in game, no other players. `read_addon_data.py --session`: fights, fight length, downtime, mana and health per fight, kill XP vs other XP, XP per hour, per character and level. Newest 4,000 records kept.
- `/wfa spells`: every spellbook spell with its live tooltip, so datamined spell numbers can be checked on any class. `/wfa go` now runs it and the probe too; the three Resto tooltips run only on a Shaman. Snapshots taken by hand now include equipped item links.
- Fix: `addonVersion` in the save file was only written when the file was created, so it kept saying 0.1.0. It now records the version that last wrote the file.
- Observed on disk, 19 Sept: the game had written `SavedVariables/WFATest.lua` for v0.1.0, so addons are enabled in the beta and the addon loads. The installed copy was still v0.1.0; v0.2.0 had never been installed. No `/wfa` command has been run yet and there is no `WoWCombatLog.txt` yet.
- Lua syntax-checked with luaparser; reader tested against a synthetic save file (probe matrix, session with secret combat-end values, spellbook filter). **Not yet run in game.** No knowledge file changed.
